# Work Proofs

Status: `STAGE_METRICS_REQUIRED`

MatVerse treats valid work as a replayable causal state transition.

## Core forms

- PoCW-MV: Proof of Causal Work
- PoEW: Proof of Economic Work
- PoSW: Proof of Scientific Work
- PoSE: Proof of Situated Event
- PoLE: Proof of Lineage Execution
- PoR: Proof of Replay
- PoG: Proof of Governance

## Rule

```text
valid work = useful state change that survives replay
```

## PoEW

Proof of Economic Work: economic value is accepted when it produces useful, admissible, replayable, persistent and traceable transformation.

## PoSW

Proof of Scientific Work: scientific value is accepted when it produces testable hypotheses, evidence, replay, lineage, dataset, benchmark, refutability or verifiable advancement.
