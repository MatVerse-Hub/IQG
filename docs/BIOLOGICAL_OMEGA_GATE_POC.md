# Biological Omega Gate PoC v0.1

Status: `STAGE_POC`

## Purpose

Run a 30-day observational, non-clinical proof of concept to measure operational load and intervention effects during interaction with persistent intelligent systems.

## Boundary

This protocol does not diagnose, treat or promise health outcomes. It observes operational load, fatigue proxies, recovery patterns and interface interventions.

## Hypothesis

```text
Biological Omega Gate can reduce overload episodes without reducing useful productivity.
```

## Minimal gates

- Sleep Gate
- Recovery Gate
- Autonomy Gate
- Entropy Gate
- Grounding Gate

## Minimal metrics

- daily cognitive load self-report
- session duration
- task switching frequency
- replay burden minutes
- intervention count
- optional sleep duration
- optional HRV
- optional typing error drift

## Interventions

- low stimulation mode
- pause agents
- summarize instead of expand
- reduce replay density
- require human confirmation
